# Arcade art generation

Generated with the built-in image_gen tool using the imagegen skill. No CLI/API-key fallback was used. The user's two supplied interface sheets informed visual direction; these are fresh original game assets, not edited copies of the sheets. Selected originals were copied into the workspace, with original generated files preserved.

Runtime art:

- `Assets/_BallQuest/Resources/Arcade/HomeBackdrop.png`: bright portrait 3D track/city background, no baked UI or ball.
- `Assets/_BallQuest/Resources/Arcade/WorldAtlas.png`: four equal horizontal strips: Sky City, Desert Canyon, Snow Peaks, Neon Night.
- `Assets/_BallQuest/Resources/Arcade/IconAtlas.png`: transparent four-by-four glossy UI icons, row-major top-down coin/gem/calendar/target, gift/cart/ball/gear, trophy/home/speaker/music, vibrate/lock/check/back.
- `Assets/_BallQuest/Resources/Arcade/AppIcon.png`: matching original carbon/cyan turbine ball launcher icon.

The player balls and live collection previews are native 3D geometry, PBR materials, procedural spherical textures and a custom reflection environment. BallPreview renders one live model and caches small one-time thumbnails. Generated background art is never used as gameplay geometry.
